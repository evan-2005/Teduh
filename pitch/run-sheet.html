Once, the day before

Set up the laptop

You need the project folder, Node 20 or newer, Ollama with the qwen2.5vl:7b model, and internet for the background map.

  1. Open two terminals in the SDP Hackathon folder (VS Code: Terminal → New Terminal, twice).
  2. First time only, install the packages:
    npm install
  3. Check .env in the project folder contains these lines. Never show an API key on screen.
    VITE_ENABLE_AI=true
AI_PROVIDER=ollama
OLLAMA_MODEL=qwen2.5vl:7b
  4. Check the model is downloaded. If it is missing, run ollama pull qwen2.5vl:7b (about 6 GB).
    ollama list
  5. Run the automated checks. All must pass.
    npm test
  6. Put a real photo of a footpath on the laptop: take one near campus around 2 pm, half in shade if you can. The fallback pitch/assets/sample-path-synthetic.jpg is a drawing, so say so if you use it.
  7. Record a backup video of the full 5-minute script, no cuts. Save it as pitch/backup-demo.mp4 and keep a copy on a phone.

Q&A

Likely questions

QuestionWhoShort answer
How accurate is the shade?StevenModelled from mapped buildings and the real sun at four times of day. OpenStreetMap has few trees here, so midday shade is understated. The pilot and the AI scan replace estimates with surveyed values, and every number shows its source.
Where do the walking numbers come from?Thien GenStation exits are real Prasarana ticket-gate counts on data.gov.my. How they split between places, and bus stop trips, are estimates. A count at the station and the mall is the first thing the pilot adds.
Does shade make it cooler or safer?Thien GenWe don’t claim that. Shade is not comfort or safety. We measure time walked in direct sun.
What would it cost SDP?Thien GenThe tool runs on open data and a laptop, so it costs little. The money is the trees and walkways, and Teduh puts that money where most people walk. Costs are bottom-up estimates; the pilot swaps in real quotes.
Why not plant trees everywhere?StevenBudgets are limited. In SS 15 one 69 m walkway does more than several tree rows because it sits on the busiest shared stretch.
Will it work on Elmina or Bukit Raja?StevenYes: Look up a place builds any area in about 40 seconds. We showed Ara Damansara.
What does the AI do?StevenIt estimates shade from a survey photo, which a person must confirm, and writes a plain summary of the plan from the numbers on screen. A check rejects any summary that invents a number. It runs locally, or on Claude in the cloud.
What happens after the hackathon?Thien GenA six-month pilot in one SDP township: survey, build one walkway and some tree rows, then compare predicted and observed shade and walker counts.
